# MikuDay
     
♥设置页：设置时间清单，滑动可更新删除改变颜色，存入预设，上方拖动，任意位置右键跳转桌面时钟♥    
♥主页：时间轴进度，包含开始结束提醒，上方拖动，任意位置右键跳转桌面时钟♥    
♥桌面时钟：可拖动，任意位置右键返回♥    
♥系统托盘：右键设置是否置顶与退出♥    

♥预设存档在   
C:\Users\你的用户名\AppData\Roaming\com.example   
♥表情包来自miratsu    
https://space.bilibili.com/3546769371695776
